# Genghis on Stellar

Public documentation for the Genghis Stellar Community Fund submission.

- [ARCHITECTURE.md](ARCHITECTURE.md): the technical architecture. It covers the Stellar payment path for people, the x402 memo bridge for AI agents, and how both connect to a payment processor that attributes deposits by memo.
- [genghis-stellar-poc](https://github.com/genghisecommerce/genghis-stellar-poc): the testnet proof of concept, live at https://genghisecommerce.github.io/genghis-stellar-poc/
- [genghis-mcp-readonly](https://github.com/genghisecommerce/genghis-mcp-readonly): the read-only agent discovery server this design builds on.
- [genghis.pro](https://www.genghis.pro): the live marketplace.

Genghis is a live marketplace for digital goods, trading since October 2025: gift cards, game keys, eSIMs and mobile top-ups, paid in crypto.
