# Genghis on Stellar

Public documentation for the Genghis Stellar Community Fund submission.

- [ARCHITECTURE.md](ARCHITECTURE.md): the technical architecture, version 2 (20 October 2026). USDC is the primary asset, received on a Genghis Stellar account; XLM is the secondary option through our payment processor; AI agents pay in USDC through standard x402 on Stellar.
- [genghis-stellar-poc](https://github.com/genghisecommerce/genghis-stellar-poc): the testnet checkout demo (USDC first, live Genghis products), live at https://genghisecommerce.github.io/genghis-stellar-poc/
- [genghis-mcp-readonly](https://github.com/genghisecommerce/genghis-mcp-readonly): the read-only agent discovery server this design builds on.
- [genghis.pro](https://www.genghis.pro): the live marketplace.

Genghis is a live marketplace for digital goods, trading since October 2025: gift cards, game keys, eSIMs and mobile top-ups, paid in crypto.
