# Genghis on Stellar

Public documentation for the Genghis Stellar Community Fund submission.

- [ARCHITECTURE.md](ARCHITECTURE.md) — the technical architecture: the Stellar payment path for people, the x402 memo bridge for AI agents, and how they connect to a payment processor that attributes deposits by memo.
- Code: [genghis-mcp-readonly](https://github.com/genghisecommerce/genghis-mcp-readonly), the read-only agent discovery server this design builds on.
- Live product: https://www.genghis.pro

Genghis is a live marketplace for digital goods — gift cards, game keys, eSIMs and mobile top-ups — paid in crypto, trading since October 2025.
